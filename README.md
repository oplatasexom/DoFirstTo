# DoFirstTo - сначала дело

Список задач, утром вместо рабочего
стола открывается экран задач, пока они не сделаны, доступны только нужные
программы и вкладки. Это мягкий замок для мотивации, а не блокировщик.
кнопка Выключить всегда на виду и пароля не спрашивает

- Windows 10 и 11, amd64 и arm64
- Один `.exe` около 8 МБ. Права администратора, служба и драйвер не нужны
- Интерфейс рисует встроенный в Windows движок WebView2

## Скачать

Последняя версия — на странице [Releases](../../releases/latest):
`dofirst-windows-amd64.exe` для обычного компьютера, `-arm64` для
Windows на ARM. В zip-архиве тот же файл под именем `DoFirstTo.exe`

Сборка не подписана сертификатом, поэтому при первом запуске Windows
покажет окно "Система Windows защитила ваш компьютер"

## Как это работает

1. **Отбой** С этого времени блокировка взведена, ночью приложение никак не мешает, если не включить отдельную
   функцию, там же выбирается, какие группы программ остаются доступны ночью
2. **Подъем** С этого времени вместо рабочего стола экран задач
3. **Задачи** У каждой галочка или таймер, группы программ, которые она
   открывает, и кнопки запуска. Таймер можно поставить на паузу и снять ее,
   когда вернешься. Задаче можно назначить дни недели, в остальные дни ее
   в списке нет. День, на который не выпало ни одной задачи, проходит без
   экрана задач и на серию не влияет
4. **Всё сделано** полный доступ до следующего отбоя, серия растет на день

Пока ты работаешь в разрешённых программах, в углу висит виджет с текущей
задачей и таймером

Проверка идёт 2-3 раза в секунду по активному окну:

| Окно | Что происходит |
|---|---|
| Разрешённая программа | ничего |
| Запрещённая программа | окно сворачивается, открывается экран задач |
| Запрещённая вкладка в разрешённом браузере | отсчёт в виджете, затем Ctrl+W |
| Три закрытые вкладки за минуту | браузер сворачивается; вернуться можно кнопкой запуска из задачи |
| Проводник, Пуск, Диспетчер задач | разрешены всегда |
| Программа не распознана | пропускается: запереть по ошибке нельзя |

### Группы программ

Что открывает задача, задается группами. Проще всего собрать группу кнопкой
"Добавить приложение" в нем четыре вкладки:

- **Каталог** - популярные программы по разделам, найденные на компьютере
  стоят первыми
- **Мои приложения** - то, что есть в меню "Пуск" (без прав администратора)
- **Открытые сейчас** - программы с открытым окном. Имя берется у самой
  запущенной программы.
- **Сайты** - слова из заголовка вкладки, можно добавить свои

Выбор записывается в строку группы, ее можно править и руками: слева от
черты программы, справа слова из заголовка вкладки

При первом запуске блокировка не включается, только после ближайшего отбоя

### Темы

На вкладке "Темы" - пять темных и пять светлых тем и свои, своя тема
задается тремя цветами, фон, основной и текст

## Установка и удаление

Запустите `DoFirstTo.exe`. Откроются настройки, автозапуск включается сам
(запись в `HKCU\...\Run`, выключается там же в настройках)

Удаление: выключить автозапуск в настройках и удалить `.exe`. Данные лежат
в `%APPDATA%\DoFirst`, служебные файлы WebView2 — в `%LOCALAPPDATA%\DoFirst`

## Сборка

Нужен только Go 1.26+ (`winget install GoLang.Go`)

```powershell
.\build.ps1 test      # go vet и тесты
.\build.ps1 build     # dist\dofirst-windows-amd64.exe и -arm64.exe
.\build.ps1 run       # запуск из исходников с отдельной папкой данных
.\build.ps1 package   # zip-архивы; установщик — если установлен NSIS
.\build.ps1 lint      # gofmt, go vet, golangci-lint (если установлен)
.\build.ps1 smoke     # самопроверка окон на настоящем WebView2
.\build.ps1 live      # живая проверка блокировки на настоящих окнах
```

Те же цели есть в `Taskfile.yml` (`task build`, `task test`, …)

```powershell
.\dist\dofirst-windows-amd64.exe --probe
```

## Устройство

```
cmd/dofirst/        сборка зависимостей, флаги, запуск
internal/
  domain/           типы: задача, группа программ, расписание, настройки
  service/
    schedule/       фаза по расписанию: свободно / ночь / задачи
    rules/          разбор правил групп и решение по окну
    session/        порядок задач, таймер с ручной паузой, заметки
    guard/          реакция на активное окно, отсчёт и закрытие вкладок
    core/           связывает расписание, сессию, сторожа и хранилище
    stats/          серия, длительность рутины, досрочные выключения
    update/         GitHub Releases, проверка подписи, замена .exe
  storage/          зашифрованные документы (AES-256-GCM, ключ под DPAPI)
  platform/win/     всё, что вызывает Win32: окна, трей, автозапуск, DPAPI
  ui/               окна на WebView2, мост страница - ядро, страницы в web/
  catalog/          заготовленный список программ и сайтов
  logo/             логотип, заданный геометрией
tools/              mkres (ресурсы .exe), sign (подпись релизов), uipreview, genicon
```

Слои зависят в одну сторону: `ui -> service -> storage`. Сервисы не знают про
Windows и получают время, окно и хранилище через интерфейсы, поэтому
тестируются подставными реализациями

Зависимости: `golang.org/x/sys` (Win32) и `github.com/wailsapp/go-webview2`
(WebView2 без CGO)

## Данные и безопасность

- Настройки, прогресс, журнал и статистика - отдельные файлы `*.dfx` в
  `%APPDATA%\DoFirst`: JSON, зашифрованный AES-256-GCM
- Ключ шифрования случайный и завернут Windows DPAPI: открыть данные может
  только та же учетная запись Windows на том же компьютере
- Журнал работы `dofirst.log` не содержит заголовков окон и текстов заметок

## Обновления

При запуске приложение в фоне спрашивает последний релиз на GitHub и, если
он новее, показывает окно "Обновить / Напомнить позже". Скачанный файл
устанавливается только при верной подписи Ed25519

Проверка включена в сборках, где заданы репозиторий и открытый ключ.
Открытый ключ лежит в `build/update.pub` и подставляется сам, закрытый
(`release.key`) в репозиторий не добавляется

Релиз собирает GitHub (`.github/workflows/ci.yml`) по тегу `v*`:

```powershell
git tag v1.2.0
git push origin v1.2.0
```

Чтобы сборки были подписаны, содержимое `release.key` кладется в секрет
репозитория `DOFIRST_SIGN_KEY`. Без секрета релиз соберется, но
установленные копии не примут его как обновление

```powershell
go run ./tools/sign keygen -out release.key      # печатает открытый ключ - его в build/update.pub
.\build.ps1 package -Version 1.2.0 -UpdateRepo owner/dofirst
```
